# 睿造打印工坊 — 业务定位调整规范

- 生成日期：2026-09-07
- 范围：全站前端（React + Vite + Tailwind），含路由、导航、页面文案、后台入口、品牌说明页、法律声明、AI 助手人设

---

## 一、背景与目标

### 问题陈述（用户原话提炼）
1. 工作室**不卖机器**。当前网站存在大量「卖机器 / 硬件评测 / 选购 / 销售政策 / 7×24 售后 / 官方授权 / 实验室集成方案」的页面、导航、入口、卡片与文案，与实际业务不符。
2. 实际要上架的内容是：**原创 IP 周边**、**PPT 课件资源**、**面向创作者的小程序/工具**（如成本价格计算）。
3. 关于我们页面：创始人是初中生，**不标注具体年龄**（原 "14 岁的中学生" 要改成更中性的表述）。
4. 法律层面需要有**免责声明**（当前 Terms 已有部分内容，但要保留并确认全站不承诺承担任何硬件交易相关法律责任）；不涉及售卖机器，也不做 "7×24 服务"、"24 小时上门" 等不现实承诺。

### 目标用户
- 教育端：中小学信息科技教师、科创社团负责人、学生
- 创作端：3D 打印爱好者 / 独立创作者
- 周边消费者：喜欢原创 IP 的青少年和家庭用户

### 目标（Goals）
| # | 目标 |
|---|------|
| G1 | 全站前台与管理员后台快速入口 **一律不再出现 "卖/选购/销售/硬件评测/设备推荐/授权渠道" 字样与入口** |
| G2 | 删除或改造 /products /advice /sales 三条路由及其页面内容，替换为符合新业务（原创 IP 周边、工具小程序、课件资源）的信息架构 |
| G3 | 关于我们（Team）创始人简介去年龄、去 "硬件选型" 人设 |
| G4 | 所有页面的 7×24 / 24 小时上门 / 假一赔十 / 售后专线等非现实承诺 **全部删除**，改造成符合一个学生工作室的合理表述 |
| G5 | AI 聊天助手（AIChatAssistant）人设从 "选购助手" → "教育资源 / 创作工具 助手"，避免出现任何具体打印机品牌推荐 |
| G6 | 法律条款（Terms / Privacy / 新增免责声明入口）保留并强化免责，确认 "本站不销售任何硬件设备、硬件相关链接仅供参考" |
| G7 | 后台 Dashboard 移除「设备管理」快速入口（但保留 /admin/printers 路由代码，**暂不删数据库和路由代码**，以避免影响现有数据库结构，用户可后续自行清理） |

### 非目标（Non-Goals）
- 不改动数据库 tables（printers 表、resources 表结构不变）
- 不重新设计视觉主题（继续沿用蓝/绿/青 渐变 + shimmer-card 风格）
- 不新增真实后端 API（原创 IP 周边、工具小程序 **只搭页面框架与占位内容**，不做真实交易支付）
- 不重写 PrinterManager 组件内部功能代码（仅移除用户可见的入口和前台页面）

## 二、功能性需求（Functional Requirements）

### FR-1：导航栏（Navbar）信息架构改造
- Navbar 顶部导航 **移除**：集成方案 (/products)、硬件评测 (/advice)
- Navbar 顶部导航 **替换/新增**：
  - "课件资源" → `/resources`（保留）
  - "原创周边" → `/products`（**页面内容全部重写**为原创 IP 周边介绍页，**保留路径复用但不新增路由**）
  - "创作工具" → 新增 `/tools` 页面（展示成本计算器等工具占位）
  - "关于我们" → `/team`（保留但改文案）
- 管理员后台入口保留不变

### FR-2：路由与页面改造
| 路由 | 原页面 | 改造策略 |
|------|-------|---------|
| `/products` | 实验室集成方案 / 硬件推荐 | **整页重写** = 「原创 IP 周边」展示页（品牌故事 + 周边分类占位卡片） |
| `/advice` | 硬件选购建议 / 打印机卡片 | **整页重写** = 「创作工具箱」页（展示即将上线的：打印成本计算器、切片参数速查、G-code 校验等工具占位） |
| `/sales` | 销售政策 / 退换货 / 授权 | **整页重写** = 「免责声明 + 服务说明」（说明不卖硬件、资源下载规则、工具使用免责、不提供 24h 售后等） |
| `/tools` |（不存在） | **新增**轻量 Tools 占位页（链接到 advice 或 advice 内部锚即可，实际重写都在 advice 里，避免路由数量膨胀——在 Plan 阶段二选一确认，默认用 "新增 /tools + 改 /advice 为 redirect" 方案） |

> ⚠️ 简化方案（优先采用）：保留 `/advice` 和 `/products` 两个路径，但内容全部重写；`/sales` 改名为 `/legal/disclaimer` 或直接重写 `/sales` 的 URL 内容 为免责声明+服务说明；**不新增路由**，减少对 App.tsx 改动量。Plan 中按这个 "路径复用、内容全换" 策略执行。

### FR-3：Home 首页核心服务区改造
- Hero 区按钮："查看选购建议" → 改文案为 "探索创作工具"
- Hero Badge 标签：保留 "3D 打印 · 信息科技 · 教育资源" 可以加 "原创 IP"
- Stat 计数器："专业评测机型 42 款" → 替换为 "原创IP形象 N 个"、"创作小工具 N 款" 等合理数字
- 核心业务三卡片（设备选型建议 / 信息科技课件 / 设备方案推荐）→ 替换为：
  1. **原创 IP 周边** → 链接 /products
  2. **课件资源库** → 链接 /resources（保留，内容不变）
  3. **创作工具箱** → 链接 /advice 新内容

### FR-4：关于我们（Team）改造
- 创始人刘宸睿 bio 去掉 "14 岁的中学生"，改为更中性：
  > 如："睿造（Rayzo）创始人，中学生创客，致力于让前沿的 3D 打印创作技术走入日常教育，让每个孩子都能享受创造的乐趣。"
- "选型咨询主管" 角色名 → 改造为 "IP 创作主管" 或 "产品研发主管"，去掉 "硬件选型 / 3D打印设备" 相关 bio
- Values 区 "专业中立 / 选购指导" 卡片改为 "原创 / 创作赋能 / 教育共享" 等符合新定位的表述

### FR-5：Footer 改造
- 品牌介绍段落：去掉 "选购建议"、"实验室建设"、"硬件评测" 等字样
- "核心业务" 区块重写为：原创 IP 周边、信息科技课件、创作工具箱、科创活动与社群
- "联系与支持"：删除 400 热线（学生工作室不现实），保留邮箱 + 地址；删除 "7×24 售后" 任何相关字样
- 页脚法律链接：销售政策 → 改名为 "免责声明"（跳 /sales 新内容）

### FR-6：AI 聊天助手（AIChatAssistant）人设改造
- 欢迎语：不再推荐打印机，变为：
  > "你好！我是睿造工坊的 AI 小助手，可以帮你：①找课件资源 ②了解原创周边 ③使用创作工具（打印成本计算、切片参数建议等）。请问你想了解什么？"
- 所有 mock 回复逻辑中出现的品牌（Bambu Lab、Anycubic、K1C、Flashforge 等）**全部删除**，替换为教育资源或工具相关的回复内容（如 "你可以在资源页找到对应的课件包"）

### FR-7：后台 Dashboard 快速入口改造
- 「设备管理」卡片：**移除快速入口**（链接删除或灰化说明 "暂未对外开放"，优先直接删除卡片）
- 保留 `/admin/printers` 的 Route 代码不变（非目标不删代码），用户将来需要时可以直接删路由代码和数据库

### FR-8：Terms / Privacy 条款改造
- Terms 中涉及：打印机入库、硬件评测数据、购买链接 buy_url、AI 扫描硬件 等术语 → 保留但加上一句总括免责声明：
  > "本站不直接销售任何硬件设备，所有与硬件相关的历史页面或链接（如存在）仅作为教育资讯和技术交流展示，不构成任何购买或代理承诺。"
- Privacy 中 "硬件评测浏览 / AI 扫描服务硬件 DeepSeek" 等描述改为中性（保留功能但强调不作商用承诺）

### FR-9：全站 "7×24 / 24 小时上门 / 售后专线 / 假一赔十" 清理
Grep 清理范围覆盖：Products、Sales、Terms、Footer、Navbar 下拉、Home 核心服务卡片。

## 三、非功能性需求（Non-Functional Requirements）

### NFR-1：零类型错误
- `tsc --noEmit` 必须通过，不可有任何 Cannot find name / Props 类型不匹配错误

### NFR-2：构建可通过
- `npm run build` 必须成功（chunk 体积过大警告可保留）

### NFR-3：URL 兼容
- 不引入新的路由文件（或引入时记得同步 App.tsx）
- 复用 `/products` `/advice` `/sales` 三个 URL 作为新内容承载入口，避免外部引用 404

### NFR-4：视觉一致性
- 继续使用 `shimmer-card`、`shimmer-border`、`section-padding`、渐变文字等现有样式 token

### NFR-5：最小侵入
- 不动后端、不动数据库、不动真实打印机管理代码组件（PrinterManager 内部功能不变）
- ResourceManager、UserManager 不动

## 四、约束、假设与开放问题

### 约束（Constraints）
1. **严禁出现任何 "卖机器 / 打印机品牌推荐 / 购买链接 / 官方授权 / 7×24 售后 / 年度维保 / 上门服务 / 假一赔十"** 等字样（含 Terms 中的示例、FAQ 问答）
2. 创始人 bio **不得出现任何具体年龄数字**（避免与隐私/形象相关争议）
3. 不新增真实支付 / 订单 / 物流 业务代码

### 假设（Assumptions）
1. `/sales` URL 对外已存在或有引用，不删除路径，只换内容
2. 原创 IP 周边与工具小程序 **没有真实素材** → 用 `text_to_image` 占位图并合理描述（遵循用户偏好中"偏好真实、反占位"的要求：我们在 spec 中保留此约束，Plan 阶段将采用「用描述性卡片 + 工作室实拍风格 placeholder」的方式处理，避免具体型号/品牌类假数据）
3. PrinterManager 组件与 printers 表代码保留不动：若用户之后手动删除路由代码再清理，不在本次改造范围。

### 开放问题（Open Questions，审批时统一解答，默认按 Plan 处理即可）
- **Q1**：AI 助手 AIChatAssistant 是整体移除还是换人设？→ 默认：换人设（保留组件，改回复逻辑）。
- **Q2**：Resources 页面里的 "选购与维护" 分类卡片保留吗？→ 默认：改名为 "创作工具与技巧"，不去除分类数组结构。
- **Q3**：Privacy / Terms 中提到的 "硬件 AI 扫描 DeepSeek 服务" 保留？→ 默认：保留功能措辞，前面加总括 "…如页面中涉及任何硬件资讯，仅为历史教育内容，不构成销售承诺"。

## 五、验收标准（Acceptance Criteria）

### AC-1 — 导航与路由（rule）
- Navbar 顶部菜单不再显示 "集成方案 / 硬件评测" 两个旧入口
- 存在 课件资源 / 原创周边 / 创作工具 / 关于我们 四个新菜单，且点击能跳转到对应页面（路径不限）
- Admin 下拉个人中心与 Navbar 后台管理入口保持可用

### AC-2 — 售卖/硬件关键字（rule，硬门槛）
- 对 `src/**` 目录执行关键字 grep（以下任一词根的展示文案出现 0 次为 Pass；**代码中的变量名 / 组件名 PrinterManager / printers 表字段 / 后台 URL 不算展示文案**）：
  - 购买 / 购买链接 / 立即购买 / 选购 / 商城 / 店铺 / 售价 / ￥ 数字价格（非资源包或等级价格）/ 机器 / 打印机 / 3D 打印设备 / 设备方案 / 硬件 / 销售 / 卖 / 代理 / 官方店 / 天猫 / 京东 / 淘宝 / 采购合同 / 报价 / 发票 / 授权书 / 假一赔十 / 7×24 / 7*24 / 24 小时 / 售后专线 / 上门 / 维保 / 退换货 / 样机试用
- **例外**："3D 打印技术"、"3D 打印课件"、"3D 创作" 等纯技术词允许

### AC-3 — Team 创始人年龄（rule）
- 全文不再出现 "14岁"、"14 岁" 等数字年龄
- Team 页三名成员 bio 中不再出现 "硬件选型 / 设备性能 / 选型咨询" 字样

### AC-4 — Home 首页新业务（rubric，0~2）
- 2 分：核心业务三卡片 100% 对应 "IP 周边 / 课件资源 / 创作工具" 且 CTA 按钮可用；统计数字与新业务一致
- 1 分：大部分更新，仍留有 1 处旧业务痕迹（如旧按钮文案）
- 0 分：核心业务三卡片仍是硬件选型

### AC-5 — 页面存在性（rule）
- `/products` `/advice` `/sales` 三条 URL 打开无白屏，且不再是原硬件/销售内容
- `/resources` `/team` `/contact` 原有资源页/联系/团队页结构保留且无报错

### AC-6 — AI 助手新人设（rule）
- 欢迎语不再包含 "选购 / 推荐 3D 打印机 / 品牌名"
- 任何 mock 回复分支不含具体打印机品牌（Bambu / Anycubic / K1C / Flashforge 等）

### AC-7 — 免责声明条款可达（rule）
- Footer 存在 "免责声明" 法律链接，点击能跳转到对应说明页（/sales 复用内容）
- 页面含一段明确的总括性文字："本站不销售任何硬件设备 / 所有硬件相关内容仅为历史资料或教育资讯 / 用户自行承担使用创作工具的结果"

### AC-8 — 构建与类型（rule）
- `npm run check` 0 error
- `npm run build` 成功 exit 0
